# Reproducibility checklist

## Before public release
- [ ] Confirm all manuscript results are generated by this release version.
- [ ] Run the notebook from a fresh kernel, top to bottom.
- [ ] Record the exact Python version.
- [ ] Freeze exact package versions after the successful final run.
- [ ] Record the exact IntegrAO version or Git commit.
- [ ] Confirm random seeds and repeated-CV settings match the manuscript.
- [ ] Confirm the canonical fold-assignment strategy matches the Methods.
- [ ] Confirm the primary metric is negative cross-entropy and its direction is stated correctly.
- [ ] Confirm bootstrap resampling is subject-level and paired where required.
- [ ] Confirm FDR correction matches the manuscript.
- [ ] Confirm the MDE analysis is labelled as sensitivity/MDE analysis, not observed power.
- [ ] Confirm exploratory drugomics clustering is clearly labelled exploratory.
- [ ] Confirm PCA in the heterogeneity figure is used for visualisation rather than cluster definition.
- [ ] Confirm all participant-level data and identifiers are excluded from the repository.
- [ ] Confirm no absolute local paths, credentials, tokens, or institutional secrets remain.
- [ ] Compare regenerated figures and tables with the final submitted manuscript.
- [ ] Create a versioned GitHub release corresponding to the submitted manuscript.
- [ ] Archive that release in Zenodo and add the DOI to the manuscript Code Availability statement.
